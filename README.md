# Netflix-Analysis

# Netflix Movies Data Analysis Project

# Problem Statement

Netflix contains thousands of movies and shows, making it difficult to identify viewing trends, popular genres, audience preferences, and content performance. This project focuses on analyzing Netflix movie datasets to discover patterns in genres, popularity, votes, and yearly releases to support data-driven business decisions and recommendation strategies.

# Key Points / Objectives

1. Analyze more than 9,000 Netflix movies using data analytics techniques.
2. Identify the most frequent movie genres available on Netflix.
3. Determine which genres receive the highest audience votes and popularity.
4. Find the movies with the highest and lowest popularity along with their genres.
5. Analyze yearly movie release trends to identify the years with the highest number of film releases.
